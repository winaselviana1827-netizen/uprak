Tutorial Praktik TKJ: File Manajemen Windows

Panduan mengelola folder dan berkas melalui File Explorer (GUI) dan Command Prompt (CLI).

1. File Manajemen Menggunakan File Explorer (GUI)

  1. Tekan tombol Windows + E untuk membuka jendela File Explorer.
  2. Pilih drive penyimpanan (misalnya Local Disk (D:)).
  3. Tekan Ctrl + Shift + N untuk membuat folder baru, lalu beri nama Praktik_TKJ.
  4. Gunakan pintasan keyboard berikut untuk mengelola file:
  • Ctrl + C : Menyalin (Copy) file atau folder.
  • Ctrl + X : Memindahkan (Cut) file atau folder.
  • Ctrl + V : Menempelkan (Paste) hasil salinan/pindahan.
  • F2 : Mengubah nama (Rename) file atau folder.
  • Delete : Menghapus file atau folder ke Recycle Bin.

2. File Manajemen Menggunakan Command Prompt (CLI)

Buka CMD (Windows + R -> ketik cmd), lalu gunakan perintah dasar berikut:

D:                        (Pindah ke drive D)
mkdir Praktik_TKJ         (Membuat folder baru bernama Praktik_TKJ)
cd Praktik_TKJ            (Masuk ke dalam folder Praktik_TKJ)
dir                       (Menampilkan daftar isi folder)
copy tugas.txt backup.txt (Menyalin file tugas.txt menjadi backup.txt)
del backup.txt            (Menghapus file backup.txt)
cd ..                     (Kembali ke folder sebelumnya)
rmdir Praktik_TKJ         (Menghapus folder kosong)
